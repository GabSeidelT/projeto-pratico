# Versionamento Semântico

## Major
    Essa versão é atualizada apenas quando não há compatibilidade nenhuma do com as versões anteriores.

## Minor
    Essa versão é atualizada quando há a adição de novas funcionalidades mantendo a compatibilidade com as versões anteriores.

## Patch
    Essa versão é utilizada para o lançamento das correções de bugs das funcionalidades adicionadas anteriormente.
